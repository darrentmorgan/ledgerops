# Issue tracker

The public repository uses GitHub issues and pull requests at
`darrentmorgan/ledgerops`. Pass `--repo darrentmorgan/ledgerops` to GitHub CLI
commands to select the repository explicitly. Do not put real organisation data in
issues.

This file describes how the maintainer runs the project; contributors are not
required to follow the review workflow below beyond opening a pull request.

Keep changes on branches and submit pull requests with the problem, resulting
behaviour, and validation evidence. Reference related issues without closing
them until their acceptance criteria and independent review are complete.
