# Triage Labels

These labels, including `ready-for-agent`, describe how the maintainer triages issues; they are not requirements for contributors. Repository guidance speaks in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Canonical triage role | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an agent  |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            |
| `wontfix`                  | `wontfix`            | Will not be actioned                     |

When an issue is assigned a triage role, use the corresponding public repository label from this table.

Confirm labels in `darrentmorgan/ledgerops` before applying them; this table does not
authorise changes to the issue tracker.
